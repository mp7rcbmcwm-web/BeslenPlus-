# BeslenPlus

Aile odaklı beslenme ve ölçüm takip uygulaması (tek dosyalık web uygulaması / PWA).

- Aile profilleri: yetişkin, hamile, emzikli, çocuk
- 250 tarif, 365 günlük öneri planı, alerji ve sağlık durumuna göre filtreleme
- Ölçüm takibi, grafikler, çocuklar için CDC VKİ-yaş persentili
- Su takibi, ilaç-besin uyarıları, diyetisyen raporu, yedekleme

Veriler yalnızca kullanıcının tarayıcısında (localStorage) saklanır; sunucuya gönderilmez.

## Uyarı

Bu uygulama genel bilgilendirme amaçlıdır; doktor veya diyetisyen önerisinin yerini tutmaz.
Tarif ve sağlık içerikleri bir uzman tarafından henüz gözden geçirilmemiştir.

## Çalıştırma

`index.html` dosyasını tarayıcıda açın veya GitHub Pages ile yayınlayın.
